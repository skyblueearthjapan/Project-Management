## 🎨 デザインフィロソフィー (v3.0)

### 色の使い方 — 極めてミニマル

```
背景       #ffffff (純白)
表面alt    #fafbfc (極薄グレー)
hairline   #eceef2 (極薄罫線)
hairline2  #dfe2e8

ink        #0c1626 (ほぼ黒の濃紺)
ink2       #5a6473 (補助テキスト)
ink3       #9aa3b2 (ミュート)
ink4       #c4cad3 (最薄)

★ accent  #06b6d4 (cyan) — 唯一のアクセント色
accent2    #0891b2 (hover)
accentSoft #ecfdff (背景tint)
```

→ **Cyan が唯一の彩度**。それ以外は全て白〜黒のグレースケール。

### タイポグラフィ
- Inter Tight + Noto Sans JP (本文)
- JetBrains Mono (工番・パス・%・日付)
- メインサイズ: 12-14px
- 見出し: 22px / 600 / -0.015em letter-spacing
- 工番表示: monoで -0.02em letter-spacing (タイトに)

### コンポーネントの特徴
- **TopBar 54px** 白基調、薄いhair border、22px の cyan ロゴ
- **フィルタタブ**: 下線型 (タブ + count chip)
- **進捗バー** 4px 高 + cyan fill + 10個の白い tick + 円ドット (現在位置)
- **モーダル** 角丸10px、深いシャドウ + blur backdrop
- **テーブル** 罫線型、surface-alt のヘッダー背景

### 主要画面の構造

#### 工番一覧 (index.html)
```
[TopBar]
  ロゴ + ナビ(工番/管理) + 検索 + [出図] + 🔔 + 山
[ページヘッダー]
  「工番」 + 件数 + フィルタタブ + 並び順
[工番リスト]
  ★ 工番(mono) | 顧客 | 製品 | N軸 | 納期 | %
    └─ 進捗バー + 10工程ラベル (現在位置強調)
```

#### 工番詳細 (detail.html)
```
[TopBar]
[ヘッダー]
  パンくず (工番 / 25214)
  工番(mono大) + 顧客 + 製品 + 納期 + [メール][出図]
  軸タブ (●ドット + 軸名 + [+追加])
[2カラム]
  [左] PDF Viewer (Marin風大表示、ツールバー sticky)
  [右 380px]
    └ 軸進捗 (4pxバー + 短縮ラベル + 軸を出図ボタン)
    └ サブタブ (図面 / 関連資料 / 履歴)
       └ ファイルリスト (PDF/DXF/XLSアイコン + 名前 + メタ)
```

#### 管理 (admin.html)
```

```

#### DXF Viewer (dxf.html)

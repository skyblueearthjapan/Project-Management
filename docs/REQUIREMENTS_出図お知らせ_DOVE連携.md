## 1. 目的・背景

- 出図のお知らせメール送信をトリガーに、**新規工番・図面・指示書・DXFをDOVEへ自動登録**し、情報を一元化する。

## 3. 用語・データモデル対応(確定)
| 業務用語 | DOVEモデル | 単位 |
|---|---|---|
| 親工番(例 LW25146) | **Job**(jobs) | 1工番=1 Job |
| 機械の軸(昇降軸/旋回軸/回転軸/前後軸/走行軸 等) | **Axis 軸**(axes) | 工番ごとに**ユーザーが手動で追加・命名**(数は可変) |
| 出図図面PDF | Axis のメイン図面(Version/パス参照) | 軸単位 |
| DXF | DxfFile(axes に紐付く) | 軸単位 |
| 工番別指示書PDF | **新カテゴリ「工番別指示書」** | **工番(Job)単位・1つのみ** |
| 関連資料/部品リスト/差し替え図面 | 既存(軸単位) | 軸単位 |

## 4. 機能要件

### 4.1 EXE — 出図のお知らせ(メール + DOVE連携)
- **軸の構成(ユーザー操作・手動)**
  - 「＋」で軸を追加し、**軸名をユーザーが入力**(昇降軸/旋回軸/回転軸/前後軸/走行軸 等。数は工番により可変)。軸の追加/削除/改名が自由にできる。
  - 各軸に **出図図面PDF**(本文にUNCパスをリンク貼付・添付なし)と **DXFフォルダ**(DOVE紐付け・添付なし)を紐付け。
  - **1回の送信で複数軸をまとめて**扱える。
  - **工番別指示書PDF**は工番に1つ。メールに**添付**。
- **工番・情報の取得**
  - 出図図面PDFのファイル名から**親工番**を自動抽出(例 `LW25146-1 …` → 親 `LW25146`)。軸名は自動取得せず**ユーザー入力**(確実性のため)。
  - 納入先・製品名は **DOVE API `/api/v1/jobs/master/search`** から取得して本文に反映。
- **LW/TS区分**: 現行どおり LW工番(工番別指示書)/ TS工番(図面集)を区別(宛先振り分け・本文文言が異なる)。
- **宛先**
  - `送付先一覧.xlsx`(ID/名前/メール/役割フラグ ○=TO, CC, ×)で自動振り分け。**Excelで編集可能**。
- **送信元**: 固定 = 木場真佐子 `m-kiba@lineworks.co.jp`(各PCのOutlook COM)。
- **本文テンプレート(現行運用準拠)**
  ```
  関係者各位
  お疲れ様です。
  出図のお知らせです。
  工番〔工番〕 〔納入先〕様向け 〔製品名〕
  図面集リンクを↓貼り付けます。
  工番別指示書を添付します。
  〔出図図面PDFのUNCパス〕（軸の数だけ）
  〔木場様 署名〕
  ```
- **フロー(確定)**: プレビュー確認ダイアログ → **メール送信** → 送信成功時に **DOVE登録** を実行。
- 送信ログ(CSV)は現行同様に残す。

### 4.2 DOVE登録(メール送信成功後に実行)
すべて**パス参照のみ**(ファイルコピー・移動・削除はしない。CLAUDE.md §2.1/§2.2 準拠)。
1. **Job 作成**: 親工番(LW25146)の Job を作成(**既存なら再利用 = upsert**)。納入先/品名は master 由来。
2. **Axis 作成**: ユーザーが命名した各軸を Axis として作成。**出図図面PDF をパス参照でその Axis に紐付け**(メイン表示)。**後日、同一工番へ軸を追加する運用に対応**(既存Jobへ Axis を追記、重複作成しない)。
3. **DXF 紐付け**: 各 Axis に DXF フォルダをパス参照で紐付け(dxf_files)。
4. **工番別指示書**: Job単位の新カテゴリ「工番別指示書」に、指示書PDFをパス参照で1件登録。
5. **送信ログ**: DOVE(`mail_logs`/`action_logs`)にも送信履歴(工番・日時・宛先TO/CC・件名)を記録。工番ごとに「いつ誰に出図通知したか」を追える。(EXE側CSVログも現行どおり併存)

### 4.3 EXE — 工番別指示書〔毎週末報告分〕
- 現行どおり**メール送信のみ**(DOVE連携なし)。

### 4.4 DOVE改修(想定)
- **「工番別指示書」カテゴリの新設**(**Job単位**。既存の関連資料/部品リスト/差し替え図面は軸単位なので、これはJob単位の新概念 → 要設計確認 = T1)。
- 工番詳細ページに「工番別指示書」フォルダボタンを追加(既存ボタンと並べ、最前に配置)。押下でPDF表示。
- EXEからの登録を受けるAPI(Job作成/Axis作成/パス参照登録)。多くは既存(`POST /api/v1/jobs`、パス参照登録 LinkModal A/Pモード、dxf_files)を再利用。

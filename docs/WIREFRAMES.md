## 0. 画面マップ

```
┌─ Home / 一覧画面 ─────────────────────────────────────────────────┐
│   TopBar + 検索 + 工番リスト（集約進捗バー + 軸別ポップオーバー）  │
│       ↓ 行クリック                                                 │
├─ Job Detail / 工番詳細 ──────────────────────────────────────────┤
│   軸タブバー（全体図 / 昇降軸 / ... / + 追加）                      │
│   ↓ 軸選択                                                         │
│   PDF Viewer (中央、大) + DXFファイルリスト (右ペイン)              │
│       ↓ DXF行クリック                                              │
├─ DXF Viewer (モーダル or 別画面) ────────────────────────────────┤
│   DXF描画 + 寸法計測（距離 / 角度）                                 │
├─ Modals ─────────────────────────────────────────────────────────┤
│   ⌘K コマンドパレット                                              │
│   JobPickerModal (工番マスタから選択)                              │
│   AxisAddModal (軸追加)                                            │
│   ReleaseModal (出図)                                              │
│   MailComposeModal (メール作成)                                    │
│   AdminModal (管理)                                                │
│   ConfirmDialog (削除確認)                                         │
└──────────────────────────────────────────────────────────────────┘
```

主な動線:
```
工番行クリック  → 工番詳細画面（軸タブ＝最初の軸）
進捗バークリック / ホバー → 軸別ブレークダウンポップオーバー
⌘K → コマンドパレット → 工番ジャンプ / アクション
ESC → 開いている最前面（モーダル/ポップオーバー）を閉じる
```

### 2.2 軸タブバー詳細 ⭐ v0.2 拡張 / v1.0.4 ではモーダル化

```
[全体図ⓒ] [昇降軸ⓘ] [旋回軸ⓟ] [走行軸ⓤ] [+追加]  │  [📋 関連資料 (3)] [🔄 差し替え図面 (2)]
                                                  ↑ セパレータで区別
```

#### 軸タブ (左側)
- 軸名の後に **小バッジ** で状態を1文字で表示:
  - `ⓒ` 完了 — 全10工程完了
  - `ⓘ` 進行中 — 出図済、工程進行中
  - `ⓟ` 未出図だが軸定義あり (pending)
  - `ⓤ` 未着手 — 軸登録だけ
- アクティブタブは下線 + 色つき bg
- 右端の `[+ 追加]` で AxisAddModal
- 軸タブクリック → PDF + DXF パネルの2画面表示

#### 共通タブ (右側、セパレータで区切る) ⭐ v0.2
- `[📋 関連資料 (N)]` — Nは登録された資料グループ数
- `[🔄 差し替え図面 (N)]` — Nは差し替え履歴件数
- 共通タブクリック → メイン領域全体がそのタブ専用ビューに切り替わる (PDF/DXF は非表示)

### 2.3 進捗ステッパー UX

各工程アイコンの動作:
- 1クリック: `pending → in_progress`
- 2クリック: `in_progress → done`
- 3クリック: `done → pending`（取消し）
- Undo Toast で 5秒以内なら戻せる

工程ホバー時:
```
┌──────────────────────────┐
│ ④ 購入                    │
│ ステータス: 進行中         │
│ 担当: （未記入）           │
│ 開始: 5/20 14:30          │
│ [担当者名を記入...]        │
└──────────────────────────┘
```

「出図前チェック」工程のみ **担当者名フィールド必須**、未記入で done に進めようとすると警告。
